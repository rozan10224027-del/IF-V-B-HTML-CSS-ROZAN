1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create web pages. It provides the basic structure of a website.

Key Points

  • HyperText: Text that links to other pages.
  • Markup: Tags used to organize content.
  • Language: Rules for creating web content.

How HTML Works

HTML uses tags to define elements on a web page. Most tags have an opening tag and a closing tag.

2. Basic HTML Structure

A basic HTML document contains the following elements:

  • <!DOCTYPE html>: Defines an HTML5 document.
  • <html>: The root element.
  • <head>: Contains document information.
  • <title>: Defines the page title.
  • <body>: Contains visible content.

Example

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Welcome to my website.</p>
</body>
</html>

3. Essential HTML Tags

  • <h1> to <h6>: Headings.
  • <p>: Paragraphs.
  • <a>: Links.
  • <img>: Images.
  • <div>: Groups of content.
  • <ul> and <ol>: Lists.
  • <li>: List items.

5. HTML Attributes

Attributes provide additional information about HTML elements.

  • id: Identifies an element.
  • class: Groups elements.
  • src: Specifies a file source.
  • href: Specifies a link destination.
  • alt: Provides alternative text for images.

Example

<a href="https://example.com">Visit Website</a>

<img src="photo.jpg" alt="A photo">

7. Project Structure

A simple website project can contain these files and folders:

my-website/
|-- index.html
|-- about.html
|-- contact.html
|-- css/
|-- js/
|-- images/
  • index.html: Main page.
  • about.html: About page.
  • contact.html: Contact page.
  • css/: CSS files.
  • js/: JavaScript files.
  • images/: Image files.
